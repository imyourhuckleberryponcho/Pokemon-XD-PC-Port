Pokemon XD PC @VERSION@ - Mac build (TEST BUILD)
================================================

PLEASE READ THIS FIRST

Nobody on the project has a Mac. This build was written on a Windows PC and is built by an automatic build
machine. Two players tried version 0.3.5 on Apple M2 Macs and sent their logs: thank you. What you see when you
try it is exactly what we need to know.

What we know and what we don't
- Known (from those two Macs): the window opens, there is a picture and sound, controllers work, settings and
  saving work, the game plays.
- Fixed since: 0.3.5 stopped after a few minutes of play ("no memory below 2 GB for a task's stack"), and
  quitting ended in a crash message. The fix is in this version; it was started on a build machine but has not
  been played on a Mac yet. If the game still stops after some minutes, please send the logs folder (below).
- Not known: how the game holds up over hours, and on Intel Macs.
- The Windows version is the tested one.

Controllers
- If A and B (confirm and cancel) seem the wrong way round on your controller, please tell us which controller
  it is. The line  gamepad1.layout = label  (or = position) in settings.ini (folder below) changes whether the
  GameCube's A, B, X and Y follow the letters printed on the buttons or their place on the controller.

What you need
- A Mac with an Apple chip (M1 or later), or an Intel Mac, with macOS 13.3 or later.
- On a Mac with an Apple chip: Rosetta 2. This program is an "Intel" program on purpose (the game needs memory
  at addresses an Apple-chip program is not allowed to use). macOS offers to install Rosetta the first time; or
  open Terminal and type:   softwareupdate --install-rosetta
- Apple has said macOS 27 is the last macOS that runs Intel programs. This build will not run on macOS 28 or
  later; a build that does is planned.
- Your own copy of Pokemon XD: Gale of Darkness (USA version, game ID GXXE01) as a disc image file
  (.iso, .gcm, .rvz ...). No game data comes with this program.

How to open it (the app is not signed by a registered developer, so macOS blocks it at first)
1. Unzip, and move "Pokemon XD.app" where you like (for example your Applications folder).
2. Double-click it. macOS says it cannot be opened / is from an unidentified developer. Click "Done"
   (not "Move to Trash").
3. Open System Settings > Privacy & Security. Scroll down to "Security". There is a line about "Pokemon XD"
   with a button "Open Anyway". Click it, confirm, and enter your password if asked.
4. From now on it opens with a double-click.
   (If you know Terminal, this does the same in one step:
      xattr -dr com.apple.quarantine "/path/to/Pokemon XD.app" )
5. The launcher opens first (a small window, as on Windows): on its Disc page choose your disc image, then press
   Play. It remembers the disc afterwards. Preset, Settings, Controls, Mods, Save and Reports are its other pages.
   (The "Extra assets" page can make models from a Pokemon Battle Revolution disc; this is new on the Mac, please
   try it and tell us what happened.)

Where your files are
  Your home folder > Library > Application Support > Pokemon XD
  (saves, settings, logs, recordings, bug reports). In Finder: menu Go > Go to Folder..., then type
  ~/Library/Application Support/Pokemon XD

Before anything else, if you are one of the first testers: the report
- Open Terminal (Applications > Utilities), type  bash  and a space, drag the file  first_run_report.sh  (next to
  this Read me) into the Terminal window, press Return.
- It looks at your Mac and at the program, starts the game once WITHOUT a disc (it stops by itself) and writes one
  text file to your Desktop: pokemon_xd_mac_report.txt. Send us that file. It holds no game data, and your user
  name is replaced in it. Nothing is sent by the script itself.
- If the game cannot start, it also says why in a message window and in the file
  ~/Library/Application Support/Pokemon XD/start_failure.txt

If it does not work
- Open Terminal and start the game itself (without the launcher) from there, so its messages can be read:
      "/path/to/Pokemon XD.app/Contents/MacOS/xd"
  (add the disc image's path after it to skip the file window; the launcher's own messages:
      "/path/to/Pokemon XD.app/Contents/MacOS/xd_launcher" )
  Copy everything it prints and send it to us, together with the newest file in
  ~/Library/Application Support/Pokemon XD/logs  (if that folder exists).
- Tell us your Mac model and macOS version (Apple menu > About This Mac).
- Nothing is ever sent by the program itself.

Updates: the launcher asks once whether it may check, shows what is new and asks before downloading; the new app is
unpacked beside this one and put in place when you press "Restart now" (the app must sit in a folder you can write
to, such as Applications, not on a disk image). Not tried on a real Mac yet.

Not in this build yet (they exist on Windows): the launcher's icon
chooser and shortcut buttons, screenshots and bug-report bundles from inside the game (F10/F12), the window icon made
from your disc.
Settings can be changed in the game's own SETTINGS page, or in settings.ini in the folder above.
