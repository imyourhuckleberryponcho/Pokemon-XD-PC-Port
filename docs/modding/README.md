# Modding Pokémon XD

> Early version: the mod format can still change.

A **mod** is a folder that changes Pokémon XD: Gale of Darkness on PC. A mod can change numbers (stats, moves, trainers, shops), text, pictures, sound
and models, add new Pokémon, moves and items, add new effects and abilities to battles, and change the story with scripts. The game reads your own
disc as always and applies the mod on top. Nothing on the disc is changed, and with every mod off the game is the plain original.

**To start:** follow [getting-started.md](getting-started.md), a first mod in about ten minutes. Most mods need no programming.

Using an AI helper? It has its own guide: [../modding-ai/README.md](../modding-ai/README.md).
