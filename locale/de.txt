= Frame pacing
> Bildtakt

= How pictures are handed to the monitor. The game always runs at the GameCube's own speed (59.94 pictures a second); this only decides how they reach the monitor. Original: every picture waits for the monitor's next refresh (vsync). Matched to the monitor: pictures are handed over on an exactly even 59.94 Hz rhythm, so on a 120/144/180 Hz monitor each stays on screen as evenly as the monitor allows; on monitors slower than 59.94 Hz (50 Hz TVs) a picture that can't be shown in time is skipped instead of holding the game up. Lowest delay: never waits for the monitor (the newest picture is shown at each refresh). With Frame rate at 60, Original behaves as Matched to the monitor (the in-between pictures need the even rhythm).
> Wie die Bilder an den Monitor übergeben werden. Das Spiel läuft immer in GameCube-Geschwindigkeit (59,94 Bilder pro Sekunde); dies bestimmt nur, wie sie den Monitor erreichen. Original: Jedes Bild wartet auf die nächste Aktualisierung des Monitors (VSync). An den Monitor angepasst: Bilder werden in einem gleichmäßigen 59,94-Hz-Takt übergeben, sodass auf einem 120/144/180-Hz-Monitor jedes so gleichmäßig wie möglich angezeigt wird; auf Monitoren unter 59,94 Hz (50-Hz-Fernseher) wird ein Bild, das nicht rechtzeitig gezeigt werden kann, übersprungen, statt das Spiel aufzuhalten. Geringste Verzögerung: wartet nie auf den Monitor (bei jeder Aktualisierung wird das neueste Bild gezeigt). Bei Bildrate 60 verhält sich Original wie An den Monitor angepasst (die Zwischenbilder brauchen den gleichmäßigen Takt).

= Frame rate
> Bildrate

= 30: the game's own pictures, as on the GameCube (most of the game draws 30 a second). 60: between two of the game's pictures the port shows an in-between picture, with the camera and every 3D object half way, so movement looks smoother.
